# Next-Gen Smart E-Commerce System 🛒
A modern multi-vendor e-commerce web application designed to connect manufacturers, wholesalers, retailers, and local handicraft sellers on a single platform.
## 📌 Project Overview
The Next-Gen Smart E-Commerce System is designed to provide a simple, organized, and user-friendly online marketplace where different types of sellers can list and manage their products while customers can browse, search, compare, purchase, and track products.

The system focuses on supporting local sellers and handicraft businesses while providing a scalable foundation for future AI-powered features.

## 🎯 Objectives

- Provide a centralized platform for multiple types of sellers.
- Allow customers to easily browse and search products.
- Provide shopping cart and order management functionality.
- Support local handicraft and small-scale sellers.
- Implement role-based access and management.
- Provide a foundation for future AI-based e-commerce features.

## 👥 User Roles

### Customer
- Register and login
- Browse products
- Search and compare products
- Add products to cart
- Place orders
- View order history

### Seller
- Add products
- Update product information
- Delete products
- Manage stock
- View customer orders

Seller types include:
- Manufacturers
- Wholesalers
- Retailers
- Local Handicraft Sellers

### Super Admin
- Manage users
- Manage sellers
- Manage products
- Manage orders
- Monitor the overall system
